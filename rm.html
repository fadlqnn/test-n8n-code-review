Simple Login Project

Project ini memiliki satu halaman login sederhana.

Expected Behaviour

  • Password harus divalidasi dengan benar.
  • Input tidak boleh keluar dari container.
  • Tombol login harus mengirimkan form.
  • Pesan sukses hanya muncul jika username dan password benar.

Challenge

Temukan seluruh bug pada project ini dan perbaiki. Tidak semua bug berupa syntax error.
